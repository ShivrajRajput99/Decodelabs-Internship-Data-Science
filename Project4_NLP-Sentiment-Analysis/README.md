# NLP Sentiment Analysis using TF-IDF and Naive Bayes

## Objective
Build a machine learning model to classify movie reviews as Positive or Negative.

## Dataset
IMDb Dataset (50,000 movie reviews)
Download from:
https://www.kaggle.com/datasets/lakshmi25npathi/imdb-dataset-of-50k-movie-reviews

## Technologies Used
- Python
- Pandas
- NLTK
- Scikit-Learn
- Matplotlib
- Seaborn

## Workflow
1. Text Preprocessing
2. Stopword Removal
3. Lemmatization
4. TF-IDF Vectorization
5. Train-Test Split
6. Naive Bayes Classifier
7. Model Evaluation

## Results
- Accuracy: 85.35%

## Conclusion
The model successfully predicts sentiment from text reviews using Natural Language Processing techniques.
